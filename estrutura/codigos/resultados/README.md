# Resultados

Esta pasta guarda as saídas geradas pelos scripts do grupo APPA. Os CSVs usam ponto e vírgula como separador e vírgula como separador decimal, seguindo a convenção da base.

Os arquivos com `03a` são da regressão linear, os arquivos com `03b` são da previsão, os arquivos com `04` são da regressão logística, e os arquivos com `05` e `06` correspondem à seleção de modelos e à reamostragem.

Para atualizar os resultados, execute os scripts a partir da raiz do repositório. Os arquivos anteriores serão substituídos pela nova execução.
